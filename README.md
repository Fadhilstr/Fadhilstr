## 🚀 Featured Projects

### [KelolaKerja](https://github.com/Fadhilstr/KelolaKerja)
**Employee Attendance & Reporting System with 3D Face Recognition Anti-Spoofing**
- Backend in Perl 5 (PSGI/uWSGI) with MVC architecture; frontend built with Vue 2 and Quasar Framework.
- Biometric verification pipeline utilizing ResNet-34 128-D facial embeddings and dual matching criteria (Euclidean Distance <= 0.42 and Cosine Similarity >= 89.0%).
- 2-stage active liveness detection: 68-point facial landmark parallax validation against 2D photo attacks, combined with frontal frame consistency locks.
- Complete Role-Based Access Control (Admin, Supervisor, Employee), daily activity approval workflows, audit trail logging, and Docker Compose orchestration.
- **Stack:** Perl 5, Vue.js, Quasar, ResNet-34, MariaDB 10.11, Redis 7, Nginx, Docker.

### [ITbantu](https://github.com/Fadhilstr/ITbantu)
**IT Service Desk & Incident Management Platform**
- Full-stack IT ticket management system supporting technical incidents, service requests, and complaints across 8 distinct IT service catalogs.
- Automated SLA tracking engine measuring Response and Resolution SLA across 4 priority levels (Critical, High, Normal, Low) with real-time breach warnings.
- Instant screenshot paste via `Ctrl + V`, drag-and-drop file attachments with preview, two-way communication threads, and internal staff notes.
- Secure attachment streaming with IDOR protection, complete state transition workflows, and Telegram bot notification integration.
- **Stack:** Next.js (App Router), TypeScript, Tailwind CSS, Prisma ORM, Telegram Bot API.

### [TebakKata (Konteks Indonesia)](https://github.com/Fadhilstr/TebakKata)
**Indonesian Semantic Similarity Word Game**
- Daily word game exploring semantic closeness in Indonesian, inspired by contextual game mechanics.
- Powered by `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` generating 384-dimensional normalized vector embeddings.
- High-performance vector distance ranking using PostgreSQL with the `pgvector` extension and an in-memory ranking matrix.
- Clean web interface with reactive gameplay, real-time rank feedback, and celebratory confetti animations.
- **Stack:** Python 3.12, FastAPI, PostgreSQL, pgvector, Vue 3, Vite, TypeScript, Tailwind CSS, Docker.

### [Barcode Generator](https://github.com/Fadhilstr/Generator-Barcode) · [Live Demo](https://generator-barcode-nine.vercel.app)
**Client-Side Barcode & QR Code Suite**
- Privacy-first barcode and QR code generator operating 100% inside browser memory without backend or server uploads.
- Real-time vector SVG rendering supporting 1D formats (Code 128, Code 39, EAN-13, EAN-8, UPC-A, UPC-E, ITF) and 2D matrix (QR Code).
- Real-time format validation complying with GS1 and ISO standards, including Modulo-10 checksum validation with automatic fix suggestions.
- Multi-resolution exports (Vector SVG, 1x to 4x print-ready PNG, dedicated print stylesheet), local history with privacy pause mode, and offline PWA support.
- **Stack:** Vue 3 (Composition API), TypeScript, Vite, JsBarcode, QRCode, Tailwind CSS, PWA.

### [Persfin](https://github.com/Fadhilstr/finance-tracker) · [Live Demo](https://finance-tracker-delta-teal.vercel.app/)
**Offline-First Personal Finance Tracker**
- Lightweight personal expense and income tracker running entirely client-side.
- Zero server dependency: local data persistence using Dexie.js over IndexedDB.
- Real-time financial calculations, responsive breakdown charts with Chart.js, monthly filter navigation, and complete JSON export and import backup options.
- **Stack:** Vue.js, Vite, Dexie.js (IndexedDB), Chart.js.
